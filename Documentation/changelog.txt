0.9.5 (current beta)

OG / NG / AE from One DLL: BNS now runs on the original pre-Next-Gen Fallout 4 (1.10.163) as well as NG and AE, from a single file - no separate download, no version-matched build. AE is the version this mod is developed and tested on. OG and NG are EXPERIMENTAL: believed correct, but not yet confirmed in-game by anyone. Please report how they go.

Robot Body Fix: A swapped actor no longer keeps its old body's parts. Swapping into a robot could leave it wearing the ORIGINAL actor's limbs - a Robobrain with Assaultron arms and no treads - and swapping a robot into a creature or human left leftover robot parts attached, which is why the odd feral ghoul had a thruster flame burning at its feet. Affects Automatron robots most visibly, since their entire body comes from an object template.

Interior / Exterior Filters: Two new keys, filterByMustBeInterior and filterByMustBeExterior, restrict a rule to indoors or outdoors. Write them on a line by themselves - no value needed. "Interior" means the Creation Kit's cell flag, so open-air places like Diamond City count as exterior. The check happens when the NPC's 3D loads, in whatever cell they load in.

Typo Warnings: Misspelled keys in your INI used to be dropped silently, which quietly made rules LESS restrictive than intended (a misspelled filter is simply no filter). They are now reported in the log with the file and line number.

Power Armor Swap Fix: Swapping a Power-Armored human into a robot (or any non-PA base) no longer leaves the new actor invisible. BNS now strips the leftover power-armor state from the source before the swap. Quest-bound gear is left untouched.

Next-Gen / 2026 Update Support: Works with the May 2026 Fallout 4 update. Tested on AE - see the OG/NG/AE entry above for the status of the other runtimes.

Dynamic Modification System: Instead of (or alongside) a swap, you can now modify an NPC in place with addFactions, addItems, and addOMODs / addOMODsToEquipment. OMODs are matched against each item's native MNAM data, so they only attach to valid weapons/armor (including Power Armor pieces), preventing crashes. OMODRandomizationPerItem (default true) controls whether the OMOD chance is rolled per item or once for the whole actor.

Test Mode (dryRun): Add dryRun = true to any rule to match and log exactly as normal while skipping every mutation. The actor is not marked as processed, so removing dryRun later lets the rule fire on the same actors. Use it to confirm your filters before committing.

EditorID Support: You no longer need to look up confusing hex codes! You can now use exact Editor IDs in your INI files (e.g., replaceBy = LCharSuperMutant instead of the old Fallout4.esm|FormID format). Requires Hydra.

Locational Filters: You can now restrict your swaps to specific areas! Want to turn Gunners into Synths, but only if they are in Diamond City or the Glowing Sea? Now you can with the new filterByLocation tags.

"Bodyguard" Spawning Mode: Instead of replacing an NPC, you can now use spawnAlongside = TargetForm to generate a brand new actor standing right next to them. Great for giving Raiders a loyal attack dog or spawning Protectrons alongside Gunners! Always use a chance filter with spawns to avoid infinite loops.

Advanced Debugging (debugLevel): Mod authors rejoice! You can now set a debugLevel (0 to 4) in your rules. If an NPC doesn't swap, the BNS log file will now tell you exactly why they failed the check so you can fix your INI faster.

Smarter AI/Faction Inheritance & Many Bugfixes: Added experimental support for AI/Faction manipulation, plus many bugfixes under the hood for a safer, smoother experience.
